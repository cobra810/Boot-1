Syntax Reference

  • <div> – Divider tag: Generic container element in HTML used to group elements.
  • class="..." – Class attribute: Defines CSS class names to style the element.
  • </div> – Closing tag: Signals the end of the div block.

Class Breakdown

1. container

Centers content horizontally and applies responsive padding so content doesn't hit the screen edges.

2. row

Acts as a flexbox row container that horizontally aligns child column elements.

3. col - md - 6

Composed of three logical parts:

  • col = Column element
  • md = Medium screens breakpoint ($\ge$768px). On smaller screens, it stacks to 100%!
  • 6 = Takes 6 out of 12 available grid columns ($6/12 = 50\%$).
4. bg-primary, bg-success, p-3

bg-primary: Blue background color.
bg-success: Green background color.
p-3: Padding spacing inside the block (padding level 3).
